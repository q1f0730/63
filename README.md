# 《性学三论》互动网页书 · Interactive Web Monograph

基于西格蒙德·弗洛伊德《性学三论》（*Drei Abhandlungen zur Sexualtheorie*, 1905 / 徐胤德文直译本 · 李银河导读）重构的纯白极简互动网页书。

视觉沿用 **Google Stitch「Atelier Monolith」**：`#FFFFFF` 纯白画布、`#09090B` 墨黑排版、`1px` 极细分割线（详见 [`DESIGN.md`](DESIGN.md)）。

---

## 怎么读（手机优先）

- **一屏一页，左右翻**：正文按屏幕分页，不再上下长滚动。手机左右滑动；电脑用 `←` `→`（或 `PageUp/PageDown`、空格）、点页面左右两侧、或底部「上一页 / 下一页」。底栏显示页码，如 `3 / 6`。电脑端是左右两页的「书本展开」版式，不是放大的手机页。
- **每个功能单独一屏**：底部（电脑在顶部）只有三个入口——**读书**（首页 + 续读卡片 + 七篇速览）、**图谱**（词典 / 裁决 / 人物 / 年表四个分栏，各自分页）、**进度**（全书目录、已读节数、字号与白噪音设置）。
- **随时知道下一步**：首页「继续阅读」卡片回到上次的章节和页；每节最后一页是「下一节」卡片，翻过最后一页自动进入下一节 / 下一篇。
- **次要内容收起来**：原典摘录、科学与考据注释、本篇要点、互动模型、词条释义，都在点开后以**独立的分页抽屉**出现，不撑长正文。

## 内容

- 全书 7 篇 36 节：李银河导读、1920 第四版原序、正编三论，以及《爱情心理学》《“文化的”性道德与现代人的精神病》两篇附论。每节都有现代中文精简正文，节末可展开 **徐胤德译原典摘录** 与 **21 世纪跨学科科学审视**。
- 7 个内嵌 SVG 互动模型（`js/schematics.js`），每篇封面页点「互动模型」打开：
  - `FIG. 00` 性学大厦奠基石柱与时代阴影审视仪
  - `FIG. 01` 人类自恋三次去中心化与意识阻抗拓扑
  - `FIG. 02` 欲望棱镜：性对象极性谱与固着阈值双轴解耦实验台
  - `FIG. 03` 1958 哈洛恒河猴双母体实验遥测（进食依附 vs 接触安慰）
  - `FIG. 04` 力比多水力分流：道德压抑闸门与升华河道
  - `FIG. 05` 温情流（*Zärtlichkeit*）与肉欲流（*Sinnlichkeit*）双波相位合成示波器
  - `FIG. 06` 文化性道德严苛刻度与国民心智活力相图
- 跨学科图谱：24 项核心概念双语词典、12 项现代科学裁决、8 位思想交锋学者、1856–2014 演进年表（32 条）。
- 书房白噪音：纯离线 Web Audio 合成，在「进度」页开关。

## 运行

### 方式一：直接双击
双击仓库根目录的 `index.html` 即可（纯脚本，无 ES module、无 CDN，`file://` 下可用）。

### 方式二：单文件离线版
```bash
python build_single.py
```
生成 `性学三论_单文件直开版.html`（把 CSS 与全部 JS 内联成一个文件，方便发给别人双击阅读）。这是构建产物，已加入 `.gitignore`，需要时重新生成即可。

### 方式三：本地静态服务
```bash
python server.py
```
Windows 用户也可以直接双击 `start.bat`。默认地址 `http://127.0.0.1:8686/index.html`。

## 自动检查

`tools/check.py` 用 Playwright 以 `file://` 方式打开 `index.html`，分别在手机（390×844，触屏）、电脑（1440×900）和平板（768×1024，触屏）视口检查：

- 控制台 / 页面错误为 0，无破图；
- 首页一屏放下，7 个篇章圆点都能被真实点击并打开对应章节；
- 36 节逐节检查：文档不纵向 / 横向滚动、没有文字被页底截断、超出栏宽或从相邻页“漏”进屏幕、节末卡片在最后一页；
- 翻页：方向键、按钮、点击右侧、手机滑动；翻过最后一页进入下一节，反向回到上一节最后一页；
- 原典 / 注释 / 要点 / 互动模型 / 目录 / 词条抽屉能打开、能各自翻页、`Esc` 关闭；
- 图谱四个分栏各自打开并翻页，搜索可用；进度页不滚动；所有按钮和链接都有可读名称。

```bash
pip install playwright && playwright install chromium   # 首次
python tools/check.py                                    # 三个视口全跑（约 3–4 分钟）
python tools/check.py --only mobile                      # 只跑手机（mobile / desktop / tablet）
python tools/check.py --chromium /usr/bin/chromium       # 使用系统 Chromium
```
退出码 0 表示全部通过。
