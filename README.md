# 《性学三论》沉浸式跨学科重读 · Interactive Web Monograph

基于西格蒙德·弗洛伊德《性学三论》（*Drei Abhandlungen zur Sexualtheorie*, 1905 / 徐胤德文无删节直译本 · 李银河导读）重构的纯白极简沉浸式互动网页书。

采用 **Google Stitch (`Atelier Monolith`)** 纯白学术画廊设计系统（`#FFFFFF` 画布、`#09090B` 墨黑排版、`1px` 极细分割线），将百年前的原典精简改写、7 座内嵌几何拓扑交互模型与 120 年现代神经科学 / 遗传学 / 依恋理论实证对照融为一体。

---

## 核心特性

- **纯白极简 · 由浅入深渐进阅读**：开场为静谧序幕扉页；进入各章后先经「序幕叩问」锚定直觉，再按小节渐进展开正文，彻底告别信息堆砌与认知过载。
- **全书 7 幕 36 节完整精简与双层文献归档**：涵盖李银河导读、1920 第四版原序、正编三论及《爱情心理学》《“文化的”性道德与现代人的精神病》两篇附论；每节底部均可按需展开 **徐胤德译原典摘录** 与 **21 世纪跨学科科学审视**。
- **7 座内嵌 SVG 拓扑交互模型（`js/schematics.js`）**：
  - `FIG. 00` 性学大厦奠基石柱与时代阴影审视仪
  - `FIG. 01` 人类自恋三次去中心化与意识阻抗拓扑
  - `FIG. 02` 欲望棱镜：性对象极性谱与固着阈值双轴解耦实验台
  - `FIG. 03` 1958 哈洛恒河猴双母体实验遥测（进食依附 vs 接触安慰）
  - `FIG. 04` 力比多水力分流：道德压抑闸门与升华河道
  - `FIG. 05` 温情流（*Zärtlichkeit*）与肉欲流（*Sinnlichkeit*）双波相位合成示波器
  - `FIG. 06` 文化性道德严苛刻度与国民心智活力相图
- **跨学科知识图谱（Index & Atlas）**：一键呼出全书 24 项核心概念双语对照词典、12 项现代脑科学实证裁决表、8 位思想交锋学者与 1856–2024 演进年表。
- **维也纳书房自然白噪音（Ambient）**：内置纯离线 Web Audio 合成器，营造安静专注的沉浸阅读场域。

## 快速运行

### 方式一：GitHub Pages / 浏览器直接访问
直接打开仓库根目录下的 `index.html`（部署至 GitHub Pages 后可直接在线访问），或下载 **`性学三论_单文件直开版.html`** 双击离线阅读。

### 方式二：本地启动轻量静态服务
```bash
python server.py
```
Windows 用户亦可直接双击运行 `启动网页书.bat`（默认监听 `http://127.0.0.1:8686`）。
